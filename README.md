# 3年で上場

2〜4人がIT企業の社長になり、3年（12期）で一番利益を出した会社が上場する、同時行動型の対戦ゲームです。2年（8期）の短いモードもあります（ローカルは設定画面、オンラインはホストがロビーで選択）。
スマホのブラウザで遊べます（縦画面向け・ダーク／ライトはOSの設定に合わせて切り替え）。

- **この端末で遊ぶ**：1台を順番に回して遊ぶホットシートモード（通信なし）
- **オンラインで遊ぶ**：各自のスマホで対戦（2〜4人）。画面には自分の手札・入札しか表示されません

## 構成

「デビューまであと1ステージ」と同じく、**Firebase Realtime Database（通信）＋ GitHub Pages（公開）** で動きます。どちらも無料枠です。

| 役割 | 使っているもの | 料金 |
|---|---|---|
| 画面 | TypeScript + React + Vite | — |
| オンライン対戦 | Firebase Realtime Database（「debut-game」プロジェクトを共用。データは `ipo_rooms` 以下） | 無料（Spark プラン） |
| 公開 | GitHub Pages（GitHub Actions が自動でビルドして公開） | 無料 |

```
src/logic/      ゲームロジック（UI・通信から独立。ローカル・オンライン・テストで共通）
  config.ts     ★数値はすべてここ（バランス調整はこのファイルだけ）
  game.ts       期の開始・入札解決・開発解決・最終決算
  view.ts       本人に見せてよい情報だけを取り出す
  bots.ts       テスト用ボット（ランダム／賢い）
src/shared/protocol.ts   オンラインの部屋データと操作（入室・開始・提出・チャット）
src/client/     画面（React）
  store.ts             通信（Firebase／ローカルテスト）
  firebase-config.ts   Firebaseの接続設定
database.rules.json  Firebaseのセキュリティルール（コピペ用）
.github/workflows/pages.yml  GitHub Pages への自動公開
tests/          単体テスト・自動対戦
```

### オンラインのしくみ

部屋の状態は `ipo_rooms/ルームID/data` に1つだけ保存し、全員がトランザクションで更新します。最後に提出した人の端末がその期の結果を計算します（サーバーなし）。
各自の画面には `view.ts` で自分の分だけを取り出して表示します。

> サーバーがないため、**データそのものは同じ部屋の全員の端末に届きます**。開発者ツールなどを使えば他社の手札や入札をのぞけてしまうので、仲間内で遊ぶ前提です（「デビューまであと1ステージ」と同じ考え方）。

## 手元で動かす

```bash
npm install
npm test          # 単体テスト＋自動対戦（ランダム600ゲーム、賢いボット300ゲーム）
npm run dev       # http://localhost:5173 で起動
```

`src/client/firebase-config.ts` の `apiKey` を `"YOUR_API_KEY"` にすると **ローカルテストモード** になり、Firebase なしで、同じブラウザの別タブ同士で対戦できます。

## Firebase の設定（1回だけ）

「デビューまであと1ステージ」で作った **debut-game** プロジェクトをそのまま使います（接続設定は `firebase-config.ts` に入力済み）。

1. https://console.firebase.google.com/ → **debut-game** → 「構築」→「Realtime Database」→「**ルール**」タブ
2. このフォルダの `database.rules.json` の中身を丸ごと貼り付けて「公開」
   - 「デビューまであと1ステージ」用のルール（`rooms`）もそのまま含まれているので、あちらのゲームも引き続き動きます

> 別のプロジェクトに分けたい場合は、新しく Firebase プロジェクトを作って Realtime Database を作成し、`firebase-config.ts` の値を差し替えてください。

## GitHub Pages で公開（無料）

1. https://github.com/ で「New repository」→ 名前（例：`ipo-game`）→ **Public** → 作成
2. このフォルダで次を実行
   ```bash
   git init
   git add .
   git commit -m "first commit"
   git branch -M main
   git remote add origin https://github.com/あなたのユーザー名/ipo-game.git
   git push -u origin main
   ```
3. リポジトリの「Settings」→ 左メニュー「Pages」→ Source を **GitHub Actions** にする
4. 「Actions」タブで「Deploy to GitHub Pages」が緑のチェックになれば完成（初回は Actions タブから「Re-run」が必要な場合があります）
   - `https://あなたのユーザー名.github.io/ipo-game/` で遊べます

更新するときは、ファイルを書き換えて `git add . && git commit -m "update" && git push` するだけです。テスト→ビルド→公開まで自動で行われます。

> 古い部屋のデータは Realtime Database の「データ」タブから `ipo_rooms` ごと削除して掃除できます（1部屋あたり十数KB程度です）。

## 仕様書で決まっていなかった部分の扱い

| 項目 | このアプリでの扱い |
|---|---|
| タグ「レガシー環境」 | 必要スキルにインフラ+1 |
| 法務チームの罰金100 | 攻撃側が支払う（誰にも入らない） |
| 特許トロールの相手にサービスがない | 効果なし（妨害成功には数える） |
| 突貫・無茶な要件の負債 | 実際に進んだ期だけ加算 |
| 遅延のペナルティ | 1期遅れるごとに−10%（0%未満にはしない） |
| 最終決算の利益 | 現金＋サービス価値（Lv×300）＋株 − 開始資金2,000（負債は含めない） |
| 3年目・冬の決算 | 最終決算の発表の最初にまとめて表示 |

## 追加した要素

- 起動時のオープニング演出（株価チャート・上場の鐘・ハンコ・紙吹雪）
- ニュース速報のティッカー（落札・スパイ発覚・大当たりなどの見出し）
- 最終決算の表彰（妨害王・鉄壁の守り・受注王・スパイマスター・ブラック企業 など）
- 各社の現金推移グラフ
- 1期目のチュートリアル、カードの長押し詳細、効果音のオン/オフ
- オンラインの密談チャット（定型文つき）
- 案件の途中放棄（開発フェーズ。違約金＝受注額の20%・評判−1、受け取り済みの中間金は返さない。`ABANDON`）
- 案件の「💰 利益の目安」シート（長押し）
- 2年モード（8期。`GAME.modes`）
- 広告（入札フェーズで1期1回。Web広告500で評判+1・テレビCM900で評判+2。広告の評判は+2まで・その年の冬の決算で消える。`ADS`・`AD`）
- 同額・同評判のときは抽選（結果発表に表示）
- 自社オフィス（3×2の床にデスク6つで開始。デスクの数が社員の上限。開発フェーズで床を1行／1列ずつ広げ、形のある部屋（休憩室2×1・会議室2×1・サーバールーム1×2・リフレッシュ室L字・研修室2×2・大会議室2×2・セキュリティ室1×1）を回転して配置。休憩室・研修室・リフレッシュ室はとなりのデスクの社員に効く。移動・撤去は100。最終決算で投資額の50%が資産。`OFFICE`・`ITEMS`・`src/logic/office.ts`）
- 社員の特技（16種類。採用候補の約23%が持っている・研修で25%の確率で目覚める。掛け持ち・爆速・リーダー・天才肌など。`TRAITS`）
- 投資（開発フェーズで今年の投資先4つに100〜1,000万円。冬の決算で倍率が決まる。国債×1.03〜1.08 から未公開株×0〜10まで。`FUNDS`）
- 研修（開発フェーズで空いている社員を研修へ。選んだスキル+1／新スキル習得・給料+5・30%で来期は休み。`TRAINING`）
- 社員のひとこと（入札・開発フェーズで10〜18秒おきに吹き出し。状況に合わせた約300パターン。`src/client/voices.ts`、ヘッダーの💬でオン/オフ）
- 業種（開始時にランダムに2つ配られ1つ選ぶ。SIer・Web制作・SaaS・AI・運用保守・コンサル。`INDUSTRIES`）。ボット4社×600ゲームで各業種の勝率は22〜28%
- 自社タブで社員の担当（案件／サービス／空き）を表示
- 社員の経験値（進んだ案件の必要スキルに経験+1、「今のレベル+1」たまるとスキル+1・給料+5、最大5。`GROWTH`）

## お金のバランス

- 開始資金は **2,000万円**
- 一括払いの案件は、**進んだ期ごとに中間金**（受注額の50%÷期間）が入り、残りは完了時に受け取ります（`INTERIM`）
- 案件の予算は `rpq × 1.5 × 期間 …`（`BUDGET.rate`）

## 自動対戦の結果（賢いボット・4人戦300ゲーム）

利益の中央値は約+6,900万円、最小でも約+900万円（赤字で終わる会社なし）。決算が赤字になる期は約16%です（調整前は25%）。
厳しすぎる／甘すぎる場合は `src/logic/config.ts` の `BUDGET.rate`・`INTERIM`・`GAME.startCash`、給料などで調整してください。
